## 사진 검증으로 추가된 기록

2026-10-10에 ‘2026 호주여행’ 공유앨범의 874개 항목(사진 792장, 동영상 82개)을 사진 앱의 무수정 원본 내보내기로 로컬 작업 폴더에 복사했다. 아래 사진 확인 결과가 기존 대화만으로 작성한 표의 미확인 상태보다 우선한다.

- 9/30: 달링하버 산책, 가게 방문, 숙소 전망과 생일 풍선.
- 10/1: 오페라하우스·서큘러 키, 페리, 타롱가 동물원 방문.
- 10/2: 시드니대학교 캠퍼스와 기념품점, 마켓 시티 주변 산책.
- 10/3: 라이온킹 공연장·관람 장면, 공연 후 가족 식사.
- 10/4: 브리즈번 공항 도착, 열차 이용, 골드코스트 숙소 전망.
- 10/5: 커럼빈 관람·캥거루 먹이주기, 해변, 허리케인스 그릴 식사, 서퍼스 파라다이스 밤거리·디저트.
- 10/6: 서퍼스 파라다이스 산책, 바다가 보이는 식당에서 가족 식사, 밤 해변.
- 10/7: 골드코스트 아침 풍경, 차량으로 브리즈번 이동, 공항 주변 장보기.
- 10/8: 귀국 전 브리즈번 공항과 기내 사진.

정확한 매장명이나 사진에 없는 세부 동선·체험은 추가하지 않았다. 원본 사진의 시간대 오프셋과 GPS를 함께 사용했고, 동영상 재인코딩 시각은 촬영일로 사용하지 않았다. 시간대 정보가 없는 항목은 표시된 촬영일과 사진 맥락을 사용하되 정확한 현지 촬영시각을 단정하지 않는다. GPS 0,0인 5개는 위치 미확인으로 처리했다. 유효 위치 좌표는 822개 항목에 있었다.

공개 허락: 사용자가 가족 얼굴 사진을 포함해 공개해도 된다고 명시했다. 예약·결제 화면, 바코드, 개인 정보가 있는 장면은 제외하고 사진 58장을 공개용으로 선별했다. 공개 파일에서 GPS·기기정보·EXIF/XMP를 제거했으며 원본 파일명도 대체했다. 원본과 비공개 분석 자료는 저장소 밖 로컬 작업 폴더에만 남긴다.

아래의 ‘반영한 근거’와 ‘아직 채우지 않은 내용’은 사진 검증 전의 대화 기반 기록이며, 사진으로 확인되지 않은 항목에만 계속 적용한다.

## 기록 원칙

- 사용자가 직접 알려준 여행 후 개요·방문지와 여행 중 발언을 우선한다.
- 과거 답변의 추천, 기존 사이트의 계획, 예약 사실을 실제 방문·체험 완료로 바꾸지 않는다.
- 도시별 숙박 날짜는 출국·귀국일과 4박·3박·1박 구성, 기존 숙소 자료를 함께 사용한다. 실제 체크인 시각은 기록하지 않는다.
- 날짜가 확인되지 않은 장소는 도시별 방문지에 남기고 특정 날짜에 배정하지 않는다.
- 사진 속 세부사항을 과거 답변만 보고 새롭게 확정하지 않는다. 원본 사진·예약 화면은 사이트에 추가하지 않는다.
- 개인 이름, 예약번호, 결제·여권 정보와 비공개 대화 링크는 싣지 않는다.

## 아직 채우지 않은 내용

- 시드니 9/30·10/1·10/3의 세부 동선과 오페라하우스·서큘러 키·타롱가 방문 날짜.
- SEA LIFE, QVB, 더 록스, 테마파크, 쇼핑몰 및 개별 식당의 실제 방문 여부. 추천만으로 추가하지 않았다.
- 코알라 사진, 먹이주기, 공연, 박물관 입장 등 개별 체험 여부.
- 브리즈번 DFO·Skygate·추천 식당 방문, 실제 이동수단·항공편 시각·소요시간·비용.
- 실제 이동거리. 「송파위례 시드니 거리」의 약 1.7만 km는 과거 답변의 거친 추정이며 실측 합계가 아니다. 대표 통계에는 사용하지 않는다.

## 유지하는 기능

- 기존 일정 데이터와 날짜 선택, 지도·길찾기, 숙소·마트·식당 안내.
- 준비 자료, 탐험 교실·퀴즈, 번역 앱, 현재 화면 링크 공유, 사진 출처.
- 기존 해시 링크. 새 기록의 날짜 링크는 숨겨진 탭에서도 해당 기록을 열고 이동한다.
- 기존 Pages 배포 파일 목록. 새 패키지·빌드 단계·서비스는 필요 없다.

기존 계획은 실제 기록과 비교할 수 있도록 보존하며, 해당 탭에는 준비 당시 자료라는 안내를 표시한다.
