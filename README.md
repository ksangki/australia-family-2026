# 우리 가족 호주 여행 · 2026

시드니 · 골드코스트 · 브리즈번을 다녀온 우리 가족의 여행 기록 사이트입니다.
2026년 9월 29일 출국 ~ 10월 8일 귀국, 성인 2명과 초6·초2 두 딸의 8박 10일을 정리합니다.

## 콘텐츠
- 기본 화면: 실제 여행 코스, 도시별 방문지, Day 1~10 기록
- 시드니 4박 → 골드코스트 3박 → 브리즈번 1박
- 출발 전 일정·호텔·이동·준비 자료는 별도 탭으로 보관
- 어린이를 위한 호주 탐험 교실과 퀴즈
- 가족 사진 58장: 날짜·도시 필터, 더 보기, 확대 보기, 키보드 좌우 이동

확인된 방문과 예약·추천을 구분하며, 사진의 촬영일·위치와 대화로 일정을 보완했습니다.
10/1 오페라하우스·타롱가, 10/2 시드니대학교, 10/3 라이온킹, 10/5 커럼빈·허리케인스 그릴을 기록했습니다.
콘텐츠 근거와 미확인 사항은 `docs/travel-record.md`를 참고하세요.

## 실행
빌드나 패키지 설치가 필요 없는 HTML/CSS/JavaScript 사이트입니다.

```sh
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다.

## 파일
- `index.html`: 실제 여행 기록, 출발 전 자료, 탐험 교실
- `app.js`: 일정 데이터와 상호작용
- `gallery.js`: 사진 필터·확대 보기·날짜별 사진 미리보기
- `photo-data.js`: 공개용 사진 목록. GPS·원본 파일명·기기정보는 포함하지 않음
- `assets/trip/`: 메타데이터를 제거한 큰 사진과 썸네일
- `style.css`: 반응형 스타일
- `harbour.jpg`: 시드니 항구 사진 (출처 및 라이선스는 사이트 하단 참조)

`#record`가 기본 화면이며 `#record-day-1` ~ `#record-day-10`으로 특정 날짜를 공유할 수 있습니다.
`#photos`에서 대표 사진 앨범을 볼 수 있습니다. 기존 `#days`, `#hotels`, `#prep`, `#learn`, `#learn-*` 링크도 유지합니다.

## 저장소 반영과 배포
`main`에 변경사항을 반영하면 기존 GitHub Pages 작업이 실행됩니다. 별도 빌드나 외부 의존성은 추가하지 않았습니다.
배포 작업은 기존 파일과 `gallery.js`, `photo-data.js`, `assets/`를 포함합니다.
공유앨범 원본·개인 메타데이터 분석 파일은 저장소에 넣지 않습니다.

## 사진 정리
공유앨범의 사진 792장·동영상 82개, 총 874개를 로컬 복사본으로 분석했습니다.
유효한 위치 좌표가 있는 항목은 822개입니다. 좌표가 0,0인 5개는 위치 미확인으로 처리했습니다.
공개 앨범은 육안 확인한 사진 58장만 선별했으며, 동영상 82개는 원본 보존·분류 대상이고 이번 공개 갤러리에는 포함하지 않습니다.
공개 사본은 최대 긴 변 1600px, 썸네일은 520px이며 EXIF/XMP 등의 메타데이터를 제거했습니다.
사진 앱의 공유앨범이나 원본을 수정·삭제하지 않았습니다.
