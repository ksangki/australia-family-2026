# 우리 가족 호주 여행 · 2026

시드니 · 골드코스트 · 브리즈번 가족 여행 안내 사이트입니다.

## 콘텐츠
- 날짜별 여행 일정과 이동 경로
- 호텔 정보와 준비 체크리스트
- 어린이를 위한 호주 탐험 교실과 퀴즈

## 실행
빌드나 패키지 설치가 필요 없는 HTML/CSS/JavaScript 사이트입니다.

```sh
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다.

## 파일
- `index.html`: 화면 및 탐험 교실
- `app.js`: 일정 데이터와 상호작용
- `style.css`: 반응형 스타일
- `harbour.jpg`: 시드니 항구 사진 (출처 및 라이선스는 사이트 하단 참조)

기존 사이트의 2026-09-25 버전 소스를 옮겼습니다. 대화에서 이후 논의한 예약 상태가 모두 반영된 것은 아닙니다.
